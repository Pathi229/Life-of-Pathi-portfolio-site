# Woodland artwork

Original AI-generated illustrations created specifically for Life of Pathi, inspired by the reference images' general visual principles: monumental organic trees, teal atmospheric depth, painterly olive foliage and warm light. No reference characters, lettering, logos, QR codes or compositions were included in the generated assets.

- `portfolio-tree-{768,1536}.webp`: transparent principal tree, independent of the forest scenery.
- `forest-clearing-{768,1536}.webp`: original painted clearing used in the closing section.
- Background tree silhouettes and foreground ferns are custom inline SVG in the Blade templates. Mist/light are separate CSS layers. Real branch/project controls and SVG highlighting overlay the principal tree.

Responsive WebP assets retain alpha transparency and total approximately 1.4 MB for both sizes of both illustrations. The principal desktop tree is approximately 650 KB; its smaller version is approximately 220 KB. No original multi-megabyte PNGs are shipped.

The painting itself stays consistent as content changes. Dashboard-managed branches, project markers, previews and pathways update dynamically. Eight branches appear in each illustrated group; the complete index and conventional collection pages provide unlimited browsing.

The locally served Cormorant Garamond title font is Latin-subsetted WOFF2 under the included SIL Open Font License (`public/fonts/storybook/OFL.txt`). Existing Sinhala and symbol font fallbacks remain available. Body text uses familiar system fonts.
